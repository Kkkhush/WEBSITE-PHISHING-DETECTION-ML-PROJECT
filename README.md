# 🛡️ Phishing Website Detection using Machine Learning

This project aims to enhance the understanding and detection of **cyber-attacks**, specifically **phishing**, by leveraging various **machine learning models**. The primary challenge addressed is identifying phishing websites based on their **URLs**, a common trick used by cybercriminals to steal sensitive data such as login credentials and banking information.

---

## 📌 Objectives

- Detect phishing websites using machine learning techniques.
- Improve prediction accuracy through data analysis and model comparison.
- Visualize key features and model performance.

---

## 🧠 Machine Learning Models Used

- ✅ Decision Tree Classifier
- 🌲 Random Forest Classifier
- ➖ Support Vector Machine (SVM)
- 🧪 Isolation Forest (Anomaly Detection - optional)
